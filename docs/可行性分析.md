# 个人 AI 分身站 — 可行性分析报告

> 版本:0.1(待审阅)
> 编制依据:PLAN.md 锁定决策、需求分析.md(草稿)、rag-kb-demo 代码库现状。
> 结论先行:**项目可行**,技术/经济/操作/法律/进度五个维度均通过,建议按 M1→M2→M3 推进;存在 4 个前置依赖(见 §9),需用户配合提供。

---

## 1. 项目概述

将 `E:\WorkBuddy\rag-kb-demo`(RAG 知识库问答系统)改造为个人 AI 分身网站:知识库蒸馏用户真实经历(简历+项目),部署到公开 URL(`zhengziheng.me`,香港服务器免备案);面试官访问后一页式浏览简历、与第一人称"我是本人"口吻的 AI 分身对话深挖项目;回答只基于知识库事实;上线前经评测集(30-50 题,通过率 ≥90%)把关。

## 2. 技术可行性 —— ✅ 高

### 2.1 核心技术已具备(直接复用,非从零开发)

| 能力 | 现状 | 证据 |
|------|------|------|
| Markdown 分块入库 | rag-kb-demo 已实现(按标题切+长度二次切+重叠窗口) | MarkdownParser/ChunkSplitter + JUnit 测试 |
| 混合检索 + Rerank | 向量+关键词 RRF 融合,启发式/LLM 双策略 | HybridRetrievalService + 测试 |
| LLM 流式生成(SSE) | OpenAI 兼容协议,DeepSeek 默认 | ChatService/OpenAiLlmClient |
| Agent 化多步问答 | ReAct 检索→反思→再检索 + 4 个工具 + SSE 思考动效 | AgentChatService + 测试 |
| 评测闭环 | Recall@K + LLM-as-judge + HTML 报告 | EvalService + 评测集 |
| 自动化测试 | 后端 45 单测 + 10 集成测试;前端 23 用例 | mvn test / vitest |
| 容器化 | 多阶段 Dockerfile + docker compose | 已有 |

→ 改造面集中在:**新增人设/seed/限流/护栏(后端新增 4 个点)+ 前端全新设计**,均为成熟模式,无未验证技术。

### 2.2 外部依赖可用

| 依赖 | 供应商 | 可用性 |
|------|--------|--------|
| LLM(生成) | DeepSeek API(OpenAI 兼容) | 需注册+充值,已有使用先例 |
| Embedding(向量) | 硅基流动 bge-m3(OpenAI 兼容) | 需注册,送免费额度;DeepSeek 无 Embedding 接口故另选 |
| 向量库 | PostgreSQL + pgvector | docker compose 一键起 |
| 服务器 | 香港轻量 2C2G(候选:椰子云 99 元/年) | 免备案,当天可用 |
| 证书 | Let's Encrypt + certbot | 免费,全自动续期 |
| 域名 | zhengziheng.me(.me,阿里云) | 需实名(几小时) |

### 2.3 技术风险与对策

| 风险 | 对策 |
|------|------|
| LLM/Embedding API 故障或超时 | 已有降级链:无 LLM key → 抽取式拼接;超时快速失败(代码已设 5s/30s 超时) |
| 香港服务器访问国内速度波动 | 单页静态+轻 API,流量极小;可后补 CDN |
| 中文检索质量不足 | 用 bge-m3 而非本地 hash;FAQ 文档兜底;评测集量化把关 |
| Agent 模式延迟(多次调用) | 限流 + token 上限;normal 模式兜底 |

## 3. 经济可行性 —— ✅ 高(年成本 <¥600)

### 3.1 成本测算

| 项目 | 费用 | 说明 |
|------|------|------|
| 域名 zhengziheng.me | ~¥80-150/年 | .me 注册,阿里云 |
| 香港服务器 2C2G | ¥99-400/年 | 椰子云 99 元/年 或 腾讯云 ~400/年 |
| LLM(DeepSeek) | ~¥2-10/月 | 按量:假设月 500 问 × 约 2.3K token/问 × ¥2/百万 ≈ ¥2-5;Agent 默认(2-3 次调用/问)时翻倍(模型名已核实:deepseek-v4-flash;单价实施时核对回填,见技术方案 §4.8) |
| Embedding(硅基流动) | ~¥0-1/月 | 知识库仅数篇 md,按量几乎为零 |
| 证书/监控/备份 | ¥0 | certbot 免费;pg_dump 定时本地备份 |
| **合计** | **约 ¥180-550/年,月均 <¥50** | 上限可控 |

### 3.2 收益分析(定性)

- 直接收益:无现金收入(个人品牌投资);
- 间接收益:① 面试官"先看先问",面试效率与候选人第一印象提升;② 展示 RAG/Agent/评测/CI 全栈工程能力(本身就是"会说话的简历");③ 简历差异化,降低海投被忽略概率;
- 投入产出比:年投入 <¥600,对比简历筛选环节的转化价值,性价比高。

### 3.3 成本控制

- 每 IP 限流(50 问/小时)+ 单次 token 上限(800)+ 登录接口限流(10 次/小时/IP,防爆破);
- 站内默认 **Agent 模式**(约 2-3 次调用/问,重点打磨流式效果),normal 为快速兜底;限流 + token 上限控成本;
- 知识库小(百级 chunk),Embedding 成本可忽略。

## 4. 操作(运营)可行性 —— ✅ 单人可维护

- **内容维护**:改/增 `resources/kb/*.md` → 重建索引接口(幂等),运营者即本人,无需他人;
- **迭代闭环**:管理页看访客提问记录 + 点赞/点踩 → 差评扩充 FAQ → 评测集验证,形成闭环;
- **运营负担**:低。匿名访客、免注册、无客服压力;仅需定期查看反馈与限流日志;
- **前提**:用户需提供真实简历数据、审改项目深挖 md(内容蒸馏是运营核心,已与用户约定分工)。

## 5. 法律与合规可行性 —— ✅ 低风险

| 事项 | 评估 |
|------|------|
| ICP 备案 | **香港服务器免备案**(备案只与服务器所在地有关,与域名后缀无关) |
| 域名实名 | .me 属国际后缀,阿里云注册需实名(身份证,几小时),无 .cn 的严格 CNNIC 约束 |
| 个人信息保护 | 仓库不含手机号/邮箱/地址;联系信息部署时经环境变量注入;网站展示经历内容=本人(站长)授权公开 |
| AI 内容合规 | AI 分身仅陈述本人简历/项目事实(第一人称、只答知识库、敏感词护栏、页脚声明"以本人为准"),个人非经营性网站,不涉及 ICP 经营许可 |
| 开源合规 | 复用自身 rag-kb-demo 代码;grill-me 技能基于 MIT(见 THIRD-PARTY-NOTICES) |
| 潜在风险 | 若未来转大陆服务器需重新备案(1-3 周)+ 页脚展示备案号;个人备案网站不得含经营性内容——本方案无 |

## 6. 进度可行性 —— ✅ 3-4 周可上线

| 阶段 | 内容 | 工期 | 出口 |
|------|------|------|------|
| M1 可聊分身(MVP) | 仓库骨架 + 后端改造(人设/seed/限流/护栏)+ fitlog/rag 蒸馏 + 前端落地页/聊天页 | 1-2 周 | 本地跑通,人工抽查 10 题 |
| M2 质量打磨 | FAQ 补齐 + 评测集 ≥90% + 管理页 | 1 周 | 评测报告通过 |
| M3 上线 | 服务器/域名、docker compose、Nginx+HTTPS、检查清单 | 3-5 天 | 公开 URL 可访问 |

- 开发全程不依赖服务器(本地跑),服务器采购可与 M1 并行;
- 主要等待项:域名实名(几小时)、备案(本方案无)、评测迭代(按差评数而定)。

## 7. 方案比选

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **A. 改造 rag-kb-demo 自建(当前方案)** | 控制力强、展示工程能力、成本低、数据自主 | 需自维护(1 人足够) | ✅ **推荐** |
| B. SaaS 平台(Coze/Dify 等)搭 AI 分身 | 搭建快(天级)、免运维 | 展示不了候选人的工程能力(求职目标落空)、知识库/数据在第三方、定制受限、免费额度有限 | ❌ 不推荐 |
| C. 纯静态简历站 + 外部 AI 链接 | 最快最简 | 体验割裂、无引用溯源、无评测把关 | ❌ 不推荐 |
| D. 外包开发 | 省心 | 成本高(数千+)、代码不可控、无法持续迭代 | ❌ 不必要 |

**结论**:方案 A 与"求职展示工程能力"的核心目标完全契合,且复用已测代码,改造量小,为最优解。

## 8. 风险分析与对策汇总

| 风险 | 等级 | 对策 |

| 小 IDC 跑路/单盘损坏(服务器选椰子云时) | 中 | 损失上限=99 元;代码在 GitHub、DB 每日备份外置、key 可重建;变慢即迁腾讯云(改 DNS+重部署,半小时) |

| 国内访问慢 | 低 | 静态资源小;可后补 CDN |

## 9. 结论与前置依赖

**结论:可行。** 技术(复用成熟)、经济(年 <¥600)、操作(单人可维护)、法律(香港免备案)、进度(3-4 周)五维全部通过;方案 A 与求职目标契合度最高,建议按 M1→M2→M3 执行。

**上线前置依赖(需用户提供,阻塞 M3):**
1. 真实简历数据(替换占位,供落地页与知识库);
2. 项目深挖内容审改(fitlog/rag 两篇初稿由我起草,用户审改);
3. DeepSeek LLM key + 硅基流动 Embedding key;
4. 服务器(下单后提供公网 IP/SSH)+ 域名实名完成。
